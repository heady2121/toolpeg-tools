About this tool

WebP can compress PNG-style images to a noticeably smaller file size, which is ideal for speeding up a website or reducing storage use without a visible quality drop.

How it works

  1. Drop or select a PNG file.
  2. It's re-encoded as WebP locally.
  3. Download the smaller WebP file.

Frequently asked questions

Does WebP keep PNG's transparency?

Yes — WebP fully supports transparency, so transparent areas are preserved.

How much smaller will the file be?

Typically 25–50% smaller than the original PNG, depending on the image.
