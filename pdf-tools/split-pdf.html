About this tool

Pull a specific range of pages out of a longer PDF, or break every page into its own file — handy for sharing just one chapter or section without sending the whole document.

How it works

  1. Drop a PDF file.
  2. Choose a page range, or split into single pages.
  3. Download the result.

Frequently asked questions

Does this reduce file size?

Splitting reduces size roughly in proportion to how many pages you extract, since it's separating pages rather than compressing them.

Can I extract multiple separate ranges at once?

Not in a single pass currently — run the tool again for a second range.
