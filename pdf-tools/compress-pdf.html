About this tool

Two ways to shrink a PDF. 'Keep text' mode recompresses the JPEG images inside your PDF and leaves text, fonts and links untouched, so the text stays selectable and searchable. It helps most on PDFs full of photos or scans stored as JPEG. 'Rasterize' mode rebuilds the PDF by rendering each page as an image at a quality you choose, which usually gets scans and image-heavy files much smaller but means text is no longer selectable or searchable.

How it works

  1. Drop a PDF file.
  2. Pick a mode — keep text searchable, or rasterize for the smallest file — and a quality level.
  3. Compress and download the smaller PDF.

Frequently asked questions

Will the text still be selectable afterward?

In 'Keep text' mode, yes — only the JPEG images inside the PDF are recompressed, and text, fonts and links are untouched. In 'Rasterize' mode, no — each page becomes an image, so text can no longer be selected, searched or copied.

Which mode should I use?

Start with 'Keep text'. If the result isn't much smaller, the PDF's size probably comes from something it doesn't touch, such as text and fonts, vector graphics, or images that aren't JPEG, and in that case the tool tells you it found nothing to save. If you don't need searchable text, 'Rasterize' often shrinks scans and image-heavy files much further.
